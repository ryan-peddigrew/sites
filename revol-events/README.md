# MARENGO: project hub concept for REVOL Events

Private preview (passcode gate): https://sites-mnj.pages.dev/revol-events/
`index.html` is ONE self-contained file (images inlined). Edit `src/app.html`, then `python3 src/build.py` and copy `src/index.html` up.

Brief (Ryan, 23 Nov 2026): project-based management app named MARENGO for REVOL Events (revolevents.com, 388 Carlaw Ave Unit W12). Projects are the main thing; three streams: daily catering drop-offs, holiday party catering across the city, and the Better Living Centre holiday run (load-in Wed + Thu, parties after). Every project opens to the same full view: run of show, staffing confirmed vs allocated vs open, hours, vendors, catering order. Plus hours, invoices, vendors, kitchen prep, team, data import (Google Sheets CSV links or CSV upload), chat helper.

All projects, clients, staff names and vendors are SAMPLE. Real: logo, photos, team (from /team), holiday menu items and prices (2026 holiday menu).
